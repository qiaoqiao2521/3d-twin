# iron 独立工作空间

3D 孪生默认打开现实工程工作台，重点是有来源的模型、结构与运动学检查。iron 保持独立仓库和独立运行入口，由孪生通过 iframe 接纳；角色外形、专属动作与变形逻辑仍归 iron 管理。

## 入口与连接

| 入口 | 地址参数 | 用途 |
| --- | --- | --- |
| 现实工程（默认） | 无参数或 `?mode=hangar` | 参考模型、结构、关节与归档来源 |
| iron · 虚拟角色 | `?mode=iron` | 角色预览、程序结构与部件检查 |
| 动作沙盒 | `?sandbox=1` 或 `?mode=sandbox` | 次级实验入口 |
| 赤星战区 | `?mode=mars_combat` | 次级游戏入口 |

无参数访问不再自动进入游戏。顶部“实验”菜单保留沙盒与游戏；两个主工作空间分别按需加载，iron 入口不初始化工程工作台的 WebGL 视口。

当前没有经过核验、可直接填写的 iron 公网地址。连接方式任选其一：

1. 在 iron 工作空间的“连接设置”填写实际运行地址；设置只保存在当前浏览器。
2. 部署孪生时设置 `VITE_IRON_URL`，再运行 `npm run build`。这是构建时配置；本地浏览器设置优先。

iron 站点需运行支持 `iron.embed` v1 的版本并允许嵌入。宿主自动附加 `embed=1` 和精确的 `parentOrigin`。未配置时显示连接说明，不加载猜测的网址。可通过“独立打开 iron”返回完整应用。

## 虚拟身份与检查边界

iron 的网格由程序生成；没有对应的实体或原始制造模型，不影响它在此进行结构浏览与动作预览。接纳时不要求伪造 URDF、CAD 文件或现实机器人来源。

- **程序装配树**描述角色蓝图分组和部件；它不是机械装配 BOM，也不自动构成关节树。
- **关节树**需要明确父子关系、轴、原点、类型和单位。工程台仅接受唯一、精确的节点标识；缺失或重名会显示出来，并禁用未绑定的控制。
- **文件存在、能显示或能运动**都不代表已具备制造条件。实体关联、几何来源、状态来源分别记录。
- iron 的长度单位保持 `unknown`，实体证据为 `none`。工程台未知尺度不补默认毫米；参考外形估算保留标识。
- 程序温度、波形和受力着色属于演示；支撑或质量数据不足时返回未校验。当前没有实机总线连接或硬件控制命令。

宿主提供角色选择、变形进度、镜头、暂停/恢复、程序结构树、选中部件、隔离和恢复显示。结构通过共享的 [`sceneInspection.ts`](../src/shared/inspection/sceneInspection.ts) 校验；部件 ID 只在对应角色与来源修订内使用。变形进度在一次拖动结束后提交，不逐帧传输完整结构。

## 修订锁与连接失败

[`integrations/iron.json`](../integrations/iron.json) 锁定所接纳的 iron 提交。生产环境要求运行端报告的完整 Git SHA 与锁文件完全一致；未知或不匹配时只允许查看，禁用宿主控制。只有开发环境且锁文件尚未指定修订时允许未锁定联调。

消息同时校验 iframe 窗口、精确来源、协议版本、请求 ID 和结构数据。协议不兼容、结构非法、连接超时与命令失败均有可见状态。切换回现实工程会卸载 iframe；重新连接重新握手。定向共享更新流程见 [iron 同步说明](iron-sync.md)，不会覆盖 iron 的角色实现。
