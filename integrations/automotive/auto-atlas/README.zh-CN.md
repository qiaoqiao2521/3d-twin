# Auto Atlas 汽车爆炸图

基于 [Auto Atlas](https://github.com/ahnuchen/auto-atlas) 的整车拆解、选件和车型切换。此副本使用主仓库的 React、Three.js、Vite 与 Tailwind 依赖。在仓库根目录执行 `npm run automotive:build` 可重新生成 `public/twins/automotive/auto-atlas/` 下的静态查看器，保留已有模型；`npm run dev` 和 `npm run build` 会自动执行该步骤。

代码使用 MIT，见 [LICENSE](LICENSE)。模型署名与许可记录在 `public/twins/automotive/data/models.json` 及 GLB 元数据中：BMW 为 Martin Trafas (TinoD2) 的 CC BY 4.0 模型；Tesla 为 Ameer Studio (uchiha.321abc) 的 CC BY 4.0 模型，以上以提供的 GLB 内嵌信息为依据。
